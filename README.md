# salamandradigital.co

Sitio web de Salamandra Digital. HTML y CSS estáticos, sin cookies ni rastreadores.

- `site/`: lo que se publica en el hosting (raíz pública).
- `site/enviar-chequeo.php`: formulario del Chequeo de Privacidad; envía por correo y no guarda datos.

Despliegue: GitHub Actions (pendiente de configurar).
